# まちのペンキ屋 いろは塗装

架空の外壁・屋根塗装店のWebサイトです。ポートフォリオ作品として制作しました。

**公開ページ：** https://huruuuuuugi.github.io/iroha-tosou/

> 店名・人物・実績・料金・電話番号・住所はすべて架空で、写真はAI生成です。
> お見積りフォームの入力内容は、どこにも送信されません。

## ページ

- `index.html`：トップページ
- `contact.html`：無料お見積り申し込みフォーム

## 工夫したところ

- **見る人に合わせた構成：** 外壁の色あせが気になり始めた50代の戸建ての持ち主を想定し、「誰が来るのか」「任せて大丈夫か」「どう仕上がるか」「いくらかかるか」の順に答えています。
- **ペンキの演出：** スクロールすると、ヘッダー下の波の形のままペンキが流れ、液体のように揺れながらヒーローを塗りつぶします。動きを減らす設定の人には演出をしません。
- **色見本：** 色を選ぶと家の外壁の色が変わり、選んだ色はフォームに引き継がれます。
- **入力の負担を減らすフォーム：** 必須項目と任意項目で画面を分けています。全角の数字やハイフン付きの電話番号も受け付け、ブラウザの「戻る」でも入力が消えません。
